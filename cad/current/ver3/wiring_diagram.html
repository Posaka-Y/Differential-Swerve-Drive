ロボコン機体 配線図

4S LiPo / LM2596 / Teensy 4.0 / ESP32 / C610×2 / M2006×2 / DualSense BT

配線時の重要ポイント

  • GND一点接地: モータGND (バッテリー−) とロジックGND (LM2596 OUT−) は必ずバッテリー側で一点接地。LM2596の入力GNDと出力GNDは基板内部で繋がっている。
  • LM2596の出力電圧調整: Teensy/ESP32を接続する前に、無負荷でテスターで5.00V ±0.05V を確認してから接続。初期状態の電圧は不定。
  • Teensy 4.0のUSB-VINパッド: 裏面の2つのパッドを繋ぐ細いトレースをカッターで切る。これを怠ると、開発中にUSBとVIN(5V)が競合して最悪Teensyが壊れる。
  • CAN終端抵抗: CANバスの両端のうち片方に120Ω抵抗 (CANH-CANL間)。もう片端のC610は内部終端があると言われているので片方だけでよい場合もあり。実機で要確認。
  • C610のCAN ID: C610のDIPスイッチで #1=0x201, #2=0x202 に設定。制御コマンドは0x200に全8バイトまとめて送信。
  • 電源投入順: バッテリー接続→メインSW ON でモータ電源とロジック電源がほぼ同時に立ち上がる。起動後1-2秒はTeensyからCANコマンドを送らないこと(C610の初期化待ち)。
  • Bluetoothペアリング: DualSenseは PS + Create ボタン長押しで青点滅、この間にESP32側でスキャン開始。

CAN制御プロトコル (参考)

  • 送信ID: 0x200 (ID 0x201-0x204 の4台分まとめて制御)
  • データ長: 8バイト
  • バイト構成: [ID1_H, ID1_L, ID2_H, ID2_L, ID3_H, ID3_L, ID4_H, ID4_L]
  • 各16bit値: 電流指令 (-10000 〜 +10000 を -10A 〜 +10A にマップ)
  • 送信周期: 1 kHz (1 ms 毎) 推奨
  • 受信ID: 0x201, 0x202 から角度/速度/電流/温度のフィードバック
