# ラジコン走行試験記録（2026-08-07）

## 結果

ユーザー実施のラジコン試験で、無線操作によって機体を走行動作させられることを確認した。操作入力から走行系までの統合経路が実機で成立した最初のマイルストーンとして記録する。

## この時点で確認できた範囲

- ラジコン操作を走行指令へ反映できる。
- 走行系を実機上で動作させられる。
- 単体・空走試験から接地状態の統合試験へ移行できる。

## 未記録・未判定

次の条件は定量logが残っていないため、今回の結果からは判定しない。

- 送信機・受信機の型番、入力方式、failsafe設定
- battery本数、試験開始／終了電圧、路面、搭載質量
- 走行速度、加減速率、走行時間、実施maneuver
- battery A/B電流、contactor後motor bus電圧、C620電流・温度
- 送信機断、通信断、CAN timeout、E-stop、Teensy reset時の停止動作
- 急制動時の回生電圧とenergy

したがって、今回の結果は「走行成立」であり、最高速、連続運転、回生、通信断またはE-stopの受入試験完了を意味しない。

## 次回の試験順序

1. 車輪周囲を隔離し、E-stop担当者を置いて低速から開始する。
2. 前後、左右、その場旋回、斜行、並進＋旋回を各正逆で実施する。
3. 通常停止、送信機停止、指令通信断、unit CAN timeout、E-stop、電源再投入を個別に確認する。
4. battery A/B電圧・電流、`MOTOR_PWR_SENSE`、各C620のrpm/current/temperature、指令値、contactor状態を同一時系列へ保存する。
5. 25%、50%、75%のように段階的に速度を上げ、各段階で停止時を含む最大電流、最低battery電圧、最大motor bus電圧、温度、CAN errorを確認する。
6. 回生logからbrake resistorの抵抗値・pulse energyとchopperの作動閾値を選定する。

高速からの急制動は、contactor後motor bus電圧を観測できる状態にしてから実施する。
