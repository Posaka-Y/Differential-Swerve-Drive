# CAN-G474 / CAN-L431ベンチテスト計画(通信・差動制御ループ実証)

## 目的

自作基板の発注前に、購入済みのMatek CAN-G474を主試験機として、2系統CAN、CAN物理層、配線、終端、1Mbps通信と差動ステアユニット1基の制御ループを検証する。CAN-L431は中央CANの対向ノードとして使う。NUCLEO-G474REは書込み復旧、自由なI/O、現行ファーム回帰確認用の予備とする。

CAN-G474はSTM32G474CE搭載でCAN 2系統のため、2バス同時動作を検証できる。ただし現行NUCLEO用ファームとはCAN2とAMT22 SPIのピンが異なる。ボード定義を分離し、CAN-G474用にCAN2=PB5/PB6、SPI2=PB13/PB14/PB15、AMT22_CS_N=PB12を設定してから使用する。

| 24V電源(LiPoまたは安定化電源)+ ヒューズ + スイッチ | C620給電。手の届く位置に遮断手段 |

## MCP2551の3.3V接続(確認済み、DS20001667G)

| 項目 | 値 | 結論 |
|---|---|---|
| TXD VIH | min 2.0V | 3.3VのG474出力で直接駆動できる |
| RXD VOH | 0.7VDD≈3.5V以上 | **5VトレラントFTピンで受ける。** PB12はFT(ピン表のFT表記を念のため確認) |
| VDD | 5V | NUCLEOの5Vピンから給電 |
| RS(スロープ制御) | 1Mbpsでは**GNDへ落とす** | モジュールのRSが抵抗でプルアップされている場合はGNDにジャンパ |

本番基板はTCAN332(3.3V)なのでこの注意はベンチ限定。CANバス上の信号レベル自体は5V系/3.3V系トランシーバで互換なので混在は問題ない。

終端の確認: 無電源でCANH-CANL間の抵抗を実測する。約60Ω=120Ωが2個で正常。約120Ω=1個なので、モジュール側かバス端にもう1個追加(ベンチの短配線なら120Ω 1個でも大抵動くが、エラーカウンタを見ること)。

C620のID設定: SETボタンでモーター1=ID1、モーター2=ID2に設定し、モジュールに書いておく。

## 段階テスト

各段階で観測値(レジスタ、カウンタ、角度、rpm)をVCP(PA2/PA3、USBでそのまま見える)へprintfし、前の段階に戻れる形で進める。

0. **CAN-G474 bring-up**: 5V給電、SWDまたはUART1 DFU、Device ID、LED/GPIOによるカスタムファーム実行を確認する。CAN-G474用リンカ設定とピン定義を選択する。
1. **2系統FDCAN試験**: CAN-G474上でCAN1(PA11/PA12)とCAN2(PB5/PB6)を内部ループバック後、同時に通常モード・1Mbpsで動かす。CAN-L431を中央CANの対向ノード、C620をCAN2側として送受信・エラーカウンタを確認する。
2. **C620フィードバック受信**: モーター指令ゼロのまま、0x201/0x202の受信(角度・rpm・電流・温度)を確認。受信周期1kHzが安定しているか。
3. **開ループ微小電流**: ホイールを浮かせ、0x200へ微小電流指令(±1A以下)。両モーターの回転方向とフィードバック符号を対応付けて記録する。
4. **AMT22読み取り**: 0x00,0x00リード、チェックビット検証、2bit右シフト、ゼロ点オフセット適用。手でステアを回して角度が単調に追従するか。起動時200ms静止を守る。
5. **モーター速度ループ**: 各モーター個別のrpm PI制御。ステップ応答をログ。
6. **差動運動学の結合**: 2モーターの和/差からホイール速度・ステア速度へ変換し、AMT22によるステア角ループを閉じる。まずステア角ホールド(ホイール速度0)、次にステア角固定+ホイール回転、最後に同時。
7. **外乱・限界確認**: ステア最大速度、rpm上限制限、指令タイムアウト時の安全停止(SET_TARGET途絶→ゼロ指令)。

合格条件はBUILD_PLANフェーズ1と同じ: AMT22が読める / C620 x2に指令が出てフィードバックが返る / 低速でステアと駆動が独立に制御できる。

## 安全

- ホイールは常に接地させない(治具固定)。
- 電流指令に上限クリップをファームで入れてから初回通電する。
- 24Vはヒューズ経由、遮断スイッチを手元に。
- AMT22は電源投入時に静止させる。
- 初回は片方のC620だけ接続して1モーターから始めてよい。

## ファーム実装項目(このテストで書くもの)

- FDCANドライバ(1Mbps、フィルタ、送受信)
- C620プロトコル(0x200指令エンコード、0x201/0x202デコード)
- AMT22ドライバ(SPI3、バイト間2.5µs/リード間40µs、チェックビット、オフセット)
- モーターrpm PIループ、差動運動学、ステア角ループ
- VCP経由の簡易CLI/テレメトリ出力

これらは自作基板でもそのまま使う。ピンはPAx/PBx名で書き、`platform/`層に隔離する(firmware/AGENTS.md準拠)。

## 補足: オドメトリユニット

3輪オドメトリ(AMT102 x3、Z相なし4線VCC/GND/A/B)+専用STM32F405RGT6基板(`docs/electrical/ODOMETRY_BOARD_REQUIREMENTS.md`)。
G474 NUCLEOではタイマEncoder Modeと上位ロジックの先行試験だけを行えるが、F405固有のクロック、VCAPを含む電源、USART2、bxCAN、Flash sectorは検証できない。
最終ベンチ試験はF405オドメトリ基板またはF405評価ボードで、TIM2/TIM3/TIM4の手回しカウント、方向符号、1回転count数まで確認する。
