# レビューチェックリスト

## システム構成

- [ ] mini PC、Teensy、各ユニットMCUの責務が分離されている
- [ ] mini PC通信断時に安全停止する
- [ ] TeensyがMotor Enableの最終判定を持つ
- [ ] 各ユニットは同一ファームでIDだけ変更できる

## 電源

- [ ] 6S LiPo x2を直列にしていない
- [ ] C620 x6へ24V系を分配している
- [ ] mini PC用12V降圧がある
- [ ] 制御系5V降圧がある
- [ ] 5V電源容量が足りている
- [ ] LiPo並列前の電圧差確認手段がある
- [ ] 各LiPo直後にヒューズがある
- [ ] 逆流防止がある
- [ ] プリチャージ経路を検討している

## 非常停止

- [ ] E-stopでC620 x6の24V主電源を物理遮断できる
- [ ] リレー/コンタクタがDC遮断定格を持つ
- [ ] コイルにフライバック対策がある
- [ ] E-stop入力がTeensyにも入る
- [ ] E-stop時にソフト側もモーター指令をゼロにする
- [ ] 非常停止表示灯がある
- [ ] NC接点でフェイルセーフ化している

## 中央通信

- [ ] 外部ハーネス名・シルクが `COMM_A/B` になっている(`CAN_H/L` と書いていない)
- [ ] 中央CAN用トランシーバ(C620用とは別)がある
- [ ] 中央CANとC620 CANが電気的に独立した別バスになっている
- [ ] FDCAN1=中央、FDCAN2=C620 の割当がドキュメントと一致している
- [ ] CAN IDが `機能ベース+unitId` の設計になっている
- [ ] ユニットのFDCANフィルタが自分宛+ESTOPのみ受信になっている
- [ ] SET_TARGET途絶時のタイムアウト安全停止がある
- [ ] バスがデイジーチェーンで、120Ω終端が物理両端の2箇所のみ
- [ ] トランシーバが3.3V品(TCAN332等)になっている

## C620 CAN

- [ ] MCUのC620_CAN_TX/RXをC620_CAN_H/Lへ直結していない
- [ ] 各ユニットにC620_CANトランシーバがある
- [ ] C620_CANがユニット内部専用になっている
- [ ] C620 ID 1/2をユニット内で使う前提になっている
- [ ] C620_CANの終端方針を確認している
- [ ] C620_CANスタブが短い

## AMT22 / SPI

- [x] AMT22のVIHを確認した(min 2.0V、3.3V直結可。出力Highも3.3Vで分圧不要)
- [ ] 全SPI信号を直結にしている(分圧・バッファを入れていない)
- [ ] SPI配線が短い
- [ ] SPIがMode 0、2MHz以下になっている
- [ ] バイト間2.5µs・リード間40µs・CS解放前3µsのウェイトをファームで入れている
- [ ] チェックビット(K1/K0)検証をファームで扱う
- [ ] AMT22起動時間200ms(静止必須)を初期化シーケンスで待っている

## ユニット基板(G474自作基板)

- [ ] 各VDDピン直近に100nF、全体に10uFバルクがある
- [ ] VDDAにフェライトビーズ+100nF+1uFがある
- [ ] 8MHz水晶+負荷容量がMCU直近にある
- [ ] BOOT0に10kプルダウン+ジャンパがある
- [ ] SWD(SWDIO/SWCLK/NRST/GND/3.3V)が引き出されている
- [ ] LDO近傍にデカップリングがある
- [ ] CANトランシーバ近傍にデカップリングがある
- [ ] IDジャンパで必要な全IDを設定できる
- [ ] シルクがPAx/PBx基準になっている
- [ ] ピン割当がNUCLEO検証時と同一である
- [ ] 予備降圧フットプリント(広入力)とバイパスジャンパがある

## 制御

- [ ] 順運動学と逆運動学が実装されている
- [ ] 操舵ゼロで最大駆動rpmが出る
- [ ] 操舵増加時に駆動上限が下がる
- [ ] モーターrpmがN_MAXを超えない
- [ ] レートリミットとローパスのパラメータを調整できる
- [ ] 高速旋回時の横滑り対策を将来追加できる構造になっている
