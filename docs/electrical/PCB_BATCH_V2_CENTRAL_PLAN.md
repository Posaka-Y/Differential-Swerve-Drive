## 2. CANコネクタ（2026-09-23最終指定）

専用CANコネクタは**横挿しJST GH 3pin、1=COMM_A、2=COMM_B、3=GND**に統一する。同日検討した駆動/ODOMの2pin案は撤回。

| 接続 | CAN端子 | GNDの扱い |
|---|---|---|
| 中央CAN3 ↔ 駆動V2 | 横挿しGH3 | CAN参照GNDと別の5V/GND電源ハーネス |
| 中央CAN1 ↔ ODOM V2 | 横挿しGH3 | CAN参照GNDと別の5V/GND電源ハーネス |
| 中央CAN2 ↔ LED/スイッチングCANノード | 横挿しGH3 | CAN参照GNDを接続し、負荷電流は電源ハーネスへ戻す |
| 既存汎用CAN拡張4pin | 既存5V/GND/COMM_A/COMM_B | 汎用ポート固有仕様を維持 |
| 駆動 ↔ C620専用CAN | 今回変更対象外 | C620ハーネス要件を維持 |

既存採用品の横挿しGH3（SM03B-GHS-TB系）を基本とし、BOMの完全注文型番・footprint・ケーブル向きを既存選定書と照合する。シリーズ/極数/向きは確定事項であり、再選定のための未確定項目にはしない。デイジーチェーン、各バス両端の120Ω終端、CAN系統分離を維持する。CAN参照GNDへLED/モータの負荷電流を流さない。

## 3. コンタクタ励磁回路の中央搭載案

ユーザーの「中央基板に追加した方が良さそう」を次回設計の基本案とする。**スイッチング基板の折り取り式CONTACTOR_DRIVERを今回の製造前提から外す。** 中央へ移すのはE228のコイル励磁用回路であり、主接点のモータ大電流は中央PCBを通さない。汎用スイッチング負荷は別CANノードのまま。

```text
24V制御電源 → コイル用ヒューズ → E-stop 1 NC → E-stop 2 NC
                                                 ↓
                                  中央 COIL+ → E228コイル
                                  中央 COIL- ← E228コイル
                                      ↓
                              中央ローサイドMOSFET → 24V帰路

Teensy MOTOR_PWR_EN → 中央gate buffer → MOSFET gate
                     入力/gate pulldownでreset・Hi-Z時OFF
```

- E-stopはMCU/CANに依存せず物理的にコイル電流を遮断する。解除だけでは再励磁せず明示再アームを要求。
- 現行Teensy pin2のMOTOR_PWR_ENを維持。既存別体案の5線J402をそのまま外へ出す仕様は改版対象。新COIL+/COIL-のRefDesと正式コネクタは回路図更新時に確定する。
- 既存案のAHCT buffer/MOSFET/抵抗/clampは転記候補。配置を移すだけで型番・定数の検証を省略しない。ゲートOFF条件、24V最大値、VDSピーク、E-stop時の解放時間を確認する。
- コイル帰路とclampのループを電力入力側で閉じ、Teensy/CAN/ADCの静かなGNDを直列に経由させない。5V電源GND・24V帰路・CAN参照GNDの実ハーネスを含む接地図を更新し、旧「別体driver＋スター1点」記述をそのまま流用しない。
- 基板内蔵24V→5V Buckを復活させる変更ではない。外部SD-25B-5→中央5V入力を維持し、24Vは既存安全ループ/コイル系として扱う。
- USBのみでは中央ロジックのデバッグが可能でも、24Vなしでコイルは励磁しない。

まだ中央KiCadへの実装・コネクタ変更・サージ検証は行っていない。2026-09-17の中央回路図PDF、転記表のJ402/別体driver節はこの改版に未追従であり、そのまま発注に使わない。

### コンタクタ状態診断（確定）

**2026-09-23確定: コンタクタ主接点の専用監視は今回実装しない。** コンタクタ補助接点入力や主接点後24Vの専用電圧監視を追加せず、駆動MCUがC620のCAN応答有無を検出し中央へ報告する補助診断を用いる。制御5Vと中央↔駆動CANはOFF後も生かす。表示は「OFF指令中・C620応答なし」とし、CAN無応答を「遮断確認済み」や溶着検出の根拠にはしない。中央との通信自体が途絶した場合はC620応答なしと混同せず「通信不明/情報期限切れ」とする。ハードNC E-stopのコイル遮断、reset/Hi-Z時OFF、明示再アームを維持。ファーム/GUI実装は別作業。

2026-09-26: E-stopループ全体の1ch監視だけを維持し、ボタン個別補助接点と予備chの監視は省略する。これはコンタクタ主接点の監視ではない。専用CONTACTOR_STATUS_N入力やMOTOR_PWR_SENSE回路は今回追加しない。

## 4. 購入数量と予備在庫

全BOM行を同じ予備倍率にしない。共通MPN単位で3基板分を合算し、使用可能在庫と検査合格の回収品を引いた不足数へ予備を加える。

`購入数 = max(0, 実装必要数 + 予備在庫目標 - 使用可能在庫 - 合格回収数)`

包装単位への切り上げはその後。回収不良品・所在不明品・他用途引当済み在庫は控除しない。

| 分類 | 初期の予備在庫目標（必要実装数に加算） | 扱い |
|---|---:|---|
| 常用抵抗（0Ω/100Ω/1k/10k等）、100nF | 各MPN 100個 | 将来基板・手直し用にまとめ買い |
| 常用1µF/2.2µF/4.7µF/10µF、汎用小信号部品 | 各MPN 50個 | 定格/温度/DC bias/パッケージを混ぜない。高単価品は再評価 |
| 特殊値抵抗・水晶負荷C | 各MPN 20個 | 同じ値でも精度・誘電体・定格の違いを確認 |
| LED | 各色・型番30個 | 極性が分かる状態で保管 |
| 常用コネクタ | 各正式型番10組、圧着端子は余裕を持つ | V2シリーズ確定後に基板側/ハウジング/端子を揃える |
| CAN TVS | 今回実装必要数中心、共通型番で予備0〜2個 | 大量在庫の対象外。**回路上の保護素子を省略する意味ではない** |
| MCU/TCAN/電源IC | 検査合格の回収品・既存在庫を優先、不足分のみ | 自動で大量予備を加算しない |

これは数量方針であり見積もり・発注済み数ではない。最新価格/MOQ/在庫と正式BOMを確認して購入表へ展開する。LED/スイッチング基板の専用品を今回必要数へ混ぜない。
