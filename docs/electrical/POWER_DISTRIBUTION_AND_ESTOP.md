# 電源分配・非常停止

## 電源構成

```text
6S LiPo x2
  |
  |-- 24Vメイン分電盤
        |-- 24V --> C620 x6
        |-- 24V --> DC-DC 24V->12V --> mini PC
        |-- 24V --> DC-DC 24V->5V  --> Teensy / センサ / 各ユニット制御基板
```

## 6S LiPo x2の扱い

6S LiPo x2は直列にしない。

| 構成 | 電圧 | 評価 |
|---|---:|---|
| 並列 | 約22.2V公称、25.2V満充電 | 推奨候補 |
| 独立系統 | 約22.2V公称 x2 | 系統分けする場合 |
| 直列 | 約44.4V公称、50.4V満充電 | C620に入れない |

並列運用時は、電圧差のあるLiPo同士を直結しない。

## バッテリ差し替え・並列保護

推奨構成:

```text
6S LiPo A -- ヒューズ -- 逆流防止/理想ダイオード --+
                                                   +-- プリチャージ -- メインリレー -- 24Vバス
6S LiPo B -- ヒューズ -- 逆流防止/理想ダイオード --+
```

要件:

- 各LiPo直後にヒューズを入れる。
- 並列化前にLiPo A/Bの電圧差を確認する(目安0.1V以内)。
- 逆流防止を入れる。
- 大電流・低損失を考えると理想ダイオード方式が望ましい。
- 24Vバス投入前にプリチャージ経路を用意する。
- 充電状態や劣化度が大きく違うパックを混ぜない。

パーツ選定:

| 項目 | 選定 | 備考 |
|---|---|---|
| バッテリコネクタ | XT90-S(アンチスパーク) | プリチャージ抵抗内蔵。第一段階はこれを手動プリチャージとして使い、専用プリチャージ回路を省略できる |
| 各LiPoヒューズ | MIDIヒューズ 60A + ホルダ | 実測電流を見て40〜80Aで見直す |
| 理想ダイオード | LM5050-1ベースのORingモジュール、またはLM5050-1 + 40V/低Rds(on) NチャネルFETで自作 | ショットキー直付けは60Aクラスでは損失・発熱が非現実的 |
| プリチャージ(恒久化する場合) | 47〜100Ω 25W抵抗 + 小型リレー、コンタクタと並列 | 投入後にメインコンタクタを閉じ、プリチャージ側を開く |

第一段階の簡易構成: 「XT90-Sで手動接続 → ヒューズ → 理想ダイオードOR → メインコンタクタ」。バッテリ2本同時運用を始める前に、まず1本運用+コネクタだけ2口で立ち上げると切り分けが楽。

## 降圧系

| 系統 | 入力 | 出力 | 用途 |
|---|---:|---:|---|
| C620 | 6S直 | 24V系 | C620 x6 |
| mini PC | 24V | 12V | mini PC |
| 制御系 | 24V | 5V | Teensy、センサ、各ユニット制御基板 |
| ユニット内 | 5V | 3.3V | NUCLEO周辺、CANトランシーバ |

制御系5V DC-DCは5V/3A以上を最低ラインとし、余裕を見て5A品を使う。

mini PC用12V DC-DCは、mini PCのピーク電力から選定する。

パーツ選定:

| 系統 | 選定 | 備考 |
|---|---|---|
| 24V→5V/5A | Mean Well SD-25B-5 | 入力19〜36V、絶縁型25W。満充電25.2V〜終止20V付近まで入力範囲内 |
| 24V→12V | Mean Well SD-50B-12 (12V/4.2A, 50W) | mini PCの実測ピークが50Wを超えるならSD-100B-12へ。**選定前にmini PCのACアダプタ定格を確認すること** |

注意:

- 上記は絶縁型なので、出力GNDは中央分電盤のスターGNDへ明示的に接続する。浮かせない。
- 5V系の負荷概算: NUCLEO x3 + AMT22 x3(各16mA) + トランシーバ + Teensy + センサで1〜2A程度。5A品で十分だが、ハーネスの電圧降下が支配的になるため、5V配線はAWG20以上・各ユニットのコネクタ直近で電圧を実測する。
- 電圧降下が問題になる場合の代替案: 24Vを各ユニットへ分配し、キャリア上のOKI-78SR-5/1.5-W36-C(入力7〜36V、5V/1.5A、三端子互換)でローカル降圧する。ノイズの多い24Vがキャリアへ入るトレードオフがあるため、まず5V集中分配で実測してから判断する。

## スターGND

```text
中央分電盤のGNDバー
  |-- LiPo (-)
  |-- C620電源GND
  |-- 24V->12V DC-DC GND
  |-- 24V->5V DC-DC GND
  |-- 制御系GND
```

原則:

- 電位は共通にする。
- 大電流リターンと制御GNDの経路は分ける。
- モータ電流が制御基板のGNDパターンを通過しないようにする。

## 非常停止

非常停止は、C620 x6への24V供給を物理的に遮断する。mini PC、Teensy、センサ、各ユニット制御基板の5V制御系は生かす。

```text
6S LiPo x2
  |
  |-- ヒューズ
  |-- メインリレー / DCコンタクタ
  |-- 24Vメインバス
        |-- C620 x6

24V制御系分岐
  |-- 24V->12V mini PC
  |-- 24V->5V 制御系
```

要件:

- 非常停止ボタンでメインリレー/コンタクタのコイル電源を落とす。
- E-stopで遮断する主対象はC620 x6の24V。
- 制御系はE-stop後も状態表示、ログ、通信、原因確認のため生存させる。
- DC遮断定格を持つリレー/コンタクタを使う。
- AC用リレーを流用しない。
- コイルにはフライバックダイオードまたはTVSを入れる。
- 非常停止入力はTeensyにも入れる。
- E-stop時はTeensy側でも即座にモータ指令をゼロにする。

安全側に倒すなら、非常停止スイッチはノーマリクローズ接点を使う。断線時にもリレーが落ちる。

パーツ選定:

| 項目 | 選定 | 備考 |
|---|---|---|
| メインコンタクタ | 密閉型DCコンタクタ(EVリレー)クラス。例: Hongfa HFE18Vシリーズ 100A、TE Kilovac EV200系 | 「24VDCを負荷電流で遮断できる」定格が必須条件。車載用12V系リレーはDC24V遮断定格が無いものが多く不可 |
| コンタクタコイル | 24Vコイル品。エコノマイザ(保持電流低減)内蔵型を優先 | 非内蔵ならコイル消費電力(数W)を5V/24V収支に入れる |
| E-stopスイッチ | 22mm ツイストリリース式・NC接点。例: IDEC XA/YWシリーズ、Omron A22E | NC接点をコイル電源ループに直列に入れる |
| コイルサージ対策 | フライバックダイオード(1N4007等)+ 必要ならTVS | 遮断応答を速くしたい場合はダイオード+ツェナー直列 |

電流の目安: C620は1台あたり連続20Aまで流せるが、本機の走行負荷での実測が先。初期は保守的に「メインヒューズ60A、コンタクタ100Aクラス」とし、実測後に見直す。

## 表示灯

| 状態 | 表示 |
|---|---|
| 非常停止中 | 赤点灯 |
| エラー | 赤点滅 |
| 待機 / 未キャリブレーション | 黄点灯 |
| キャリブレーション中 | 黄点滅 |
| 動作可能 | 緑点灯 |
| 通信断 | 青点滅または赤黄交互 |

表示灯はGUIを見なくても安全状態が分かる位置に置く。
