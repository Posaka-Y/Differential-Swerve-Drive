# 電源分配・非常停止

## 電源構成

```text
6S LiPo x2
  |
  |-- 24Vメイン分電盤
        |-- 24V --> C620 x6
        |-- 24V --> DC-DC 24V->12V --> mini PC
        |-- 24V --> DC-DC 24V->5V  --> Teensy / センサ / 各ユニット制御基板
```

## 6S LiPo x2の扱い

6S LiPo x2は直列にしない。

| 構成 | 電圧 | 評価 |
|---|---:|---|
| 並列 | 約22.2V公称、25.2V満充電 | 推奨候補 |
| 独立系統 | 約22.2V公称 x2 | 系統分けする場合 |
| 直列 | 約44.4V公称、50.4V満充電 | C620に入れない |

並列運用時は、電圧差のあるLiPo同士を直結しない。

## バッテリ差し替え・並列保護

推奨構成:

```text
6S LiPo A -- ヒューズ -- 逆流防止/理想ダイオード --+
                                                   +-- プリチャージ -- メインリレー -- 24Vバス
6S LiPo B -- ヒューズ -- 逆流防止/理想ダイオード --+
```

要件:

- 各LiPo直後にヒューズを入れる。
- 並列化前にLiPo A/Bの電圧差を確認する(目安0.1V以内)。
- 逆流防止を入れる。
- 大電流・低損失を考えると理想ダイオード方式が望ましい。
- 24Vバス投入前にプリチャージ経路を用意する。
- 充電状態や劣化度が大きく違うパックを混ぜない。

パーツ選定:

| 項目 | 選定 | 備考 |
|---|---|---|
| バッテリコネクタ | XT90-S(アンチスパーク) | プリチャージ抵抗内蔵。第一段階はこれを手動プリチャージとして使い、専用プリチャージ回路を省略できる |
| 各LiPoヒューズ | MIDIヒューズ 60A + ホルダ | 実測電流を見て40〜80Aで見直す |
| 理想ダイオード | LM5050-1ベースのORingモジュール、またはLM5050-1 + 40V/低Rds(on) NチャネルFETで自作 | ショットキー直付けは60Aクラスでは損失・発熱が非現実的 |
| プリチャージ(恒久化する場合) | 47〜100Ω 25W抵抗 + 小型リレー、コンタクタと並列 | 投入後にメインコンタクタを閉じ、プリチャージ側を開く |

第一段階の簡易構成: 「XT90-Sで手動接続 → ヒューズ → 理想ダイオードOR → メインコンタクタ」。バッテリ2本同時運用を始める前に、まず1本運用+コネクタだけ2口で立ち上げると切り分けが楽。

## 降圧系

| 系統 | 入力 | 出力 | 用途 |
|---|---:|---:|---|
| C620 | 6S直 | 24V系 | C620 x6 |
| mini PC | 24V | 12V | mini PC |
| 制御系 | 24V | 5V | Teensy、センサ、各ユニット制御基板 |
| ユニット内 | 5V | 3.3V | NUCLEO周辺、CANトランシーバ |

制御系5V DC-DCは5V/3A以上を最低ラインとし、余裕を見て5A品を使う。

mini PC用12V DC-DCは、mini PCのピーク電力から選定する。

パーツ選定:

| 系統 | 選定 | 備考 |
|---|---|---|
| 24V→5V/5A | Mean Well SD-25B-5 | 入力19〜36V、絶縁型25W。満充電25.2V〜終止20V付近まで入力範囲内 |
| 24V→12V | Mean Well SD-50B-12 (12V/4.2A, 50W) | mini PCの実測ピークが50Wを超えるならSD-100B-12へ。**選定前にmini PCのACアダプタ定格を確認すること** |

mini PCはGMKtec NucBox G2を採用する。流通仕様では付属電源12V/3A(36W)、給電専用USB Type-C入力とされているため、`SD-50B-12`(12V/4.2A、50W)で定格上は給電可能。次を実機で最終確認する。

- 付属ACアダプタ銘板が12V/3Aであること
- 給電専用USB-C端子の極性/結線と、USB PD交渉を必要としない固定12V入力であること
- CPU高負荷、USB周辺機器接続、起動時を含む24V入力電流と12V電圧降下
- `SD-50B-12`の出力調整、配線損失込みでG2入力端の許容電圧内に収まること

給電ケーブルはG2専用として固定・識別し、一般的なUSB-C機器へ12Vを誤接続できない運用とする。mini PC電源はモータ用コンタクタより前の常時通電制御系へ接続し、E-stop後も生存させる。

注意:

- 上記は絶縁型なので、出力GNDは中央分電盤のスターGNDへ明示的に接続する。浮かせない。
- 5V系の負荷概算: NUCLEO x3 + AMT22 x3(各16mA) + トランシーバ + Teensy + センサで1〜2A程度。5A品で十分だが、ハーネスの電圧降下が支配的になるため、5V配線はAWG20以上・各ユニットのコネクタ直近で電圧を実測する。
- 電圧降下が問題になる場合の代替案: 24Vを各ユニットへ分配し、キャリア上のOKI-78SR-5/1.5-W36-C(入力7〜36V、5V/1.5A、三端子互換)でローカル降圧する。ノイズの多い24Vがキャリアへ入るトレードオフがあるため、まず5V集中分配で実測してから判断する。

## スターGND

```text
中央分電盤のGNDバー
  |-- LiPo (-)
  |-- C620電源GND
  |-- 24V->12V DC-DC GND
  |-- 24V->5V DC-DC GND
  |-- 制御系GND
```

原則:

- 電位は共通にする。
- 大電流リターンと制御GNDの経路は分ける。
- モータ電流が制御基板のGNDパターンを通過しないようにする。

## 非常停止

非常停止は、C620 x6への24V供給を物理的に遮断する。mini PC、Teensy、センサ、各ユニット制御基板の5V制御系は生かす。

```text
6S LiPo x2
  |
  |-- ヒューズ
  |-- メインリレー / DCコンタクタ
  |-- 24Vメインバス
        |-- C620 x6

24V制御系分岐
  |-- 24V->12V mini PC
  |-- 24V->5V 制御系
```

要件:

- 非常停止ボタンは機体上の異なる位置に2個設け、両方のNC安全接点をコンタクタコイル電源ループへ直列に入れる。どちらか一方の押下または配線断でコンタクタを解放する。
- 非常停止ボタンでメインリレー/コンタクタのコイル電源を落とす。
- E-stopで遮断する主対象はC620 x6の24V。
- 制御系はE-stop後も状態表示、ログ、通信、原因確認のため生存させる。
- DC遮断定格を持つリレー/コンタクタを使う。
- AC用リレーを流用しない。
- コイルにはフライバックダイオードまたはTVSを入れる。
- 非常停止入力はTeensyにも入れる。
- E-stop時はTeensy側でも即座にモータ指令をゼロにする。

安全側に倒すなら、非常停止スイッチはノーマリクローズ接点を使う。断線時にもリレーが落ちる。

### 非常停止ボタン内蔵24V LED

非常停止ボタン2個の内蔵24V LEDは、Teensyやソフトウェアを介さず点灯できるハードワイヤ回路にする。LED電源はE-stop後も生きるヒューズ付き`24V_CTRL`から取る。

- 常時照光にする場合は、各LEDを`24V_CTRL`とGNDの間へ個別に接続する。
- 押されたボタンだけを点灯する場合は、各ボタンに安全用NC接点とは別のNO補助接点を追加し、`24V_CTRL -> NO補助接点 -> 内蔵LED -> GND`とする。
- LEDを安全用NC接点と並列に接続しない。LED電流がコンタクタコイルへ回り込む経路を作らない。
- 「常時点灯」「押下時点灯」「モータ電源遮断時点灯」のどれを要求するかは操作パネル設計時に確定する。

### コンタクタ励磁回路

Teensy中央基板にコンタクタコイルのローサイドドライバを実装する。安全遮断の主経路はあくまで2個のE-stop NC接点であり、Teensyは励磁許可のみを行う。

```text
24V_CTRL -- fuse -- ESTOP1_NC -- ESTOP2_NC -- contactor coil -- MOSFET -- GND
                                                     |-- surge clamp --|
```

- MOSFETは3.3V GPIOで確実に駆動でき、コイル電流・サージに余裕のある品を選ぶ。
- Gate pulldownにより、Teensy未起動・リセット・コネクタ断ではコンタクタOFFとする。
- コイル両端にフライバックダイオードまたはTVS/ツェナー方式のクランプを設ける。部品値はコンタクタのコイル仕様と必要な解放時間を確認後に決める。
- E-stop解除だけで自動再励磁しない。解除後に明示的な再アーム操作と安全条件成立を要求する。

### Teensyからの遠隔停止

Teensyは`MOTOR_PWR_EN`をOFFにすることでコンタクタを解放し、mini PCまたは将来の遠隔操作系からモータ主電源を遮断できるようにする。

- 遠隔停止指令を受信したら、各ユニットへdisable/電流ゼロを送ったうえで、待ち時間に依存せず`MOTOR_PWR_EN`をOFFにする。CAN送信不能でもコンタクタ遮断は実行する。
- 遠隔停止状態はTeensy内でラッチする。通信復帰、E-stopボタンの解除、Teensyの通常状態遷移だけで自動再励磁しない。
- 再励磁には明示的な再アーム操作、2個のE-stop解除、通信・ユニット・電源状態の安全条件成立を要求する。
- Teensyリセット、ハング、電源断、GPIO Hi-ZではGate pulldownによりコンタクタOFFとなる。
- mini PC、一般無線、USB、通常ファームウェアによる停止は補助的な遠隔停止であり、安全規格上の非常停止機器とは区別する。安全機能としての無線非常停止が必要になった場合は、安全認証された受信機の強制ガイド接点を物理E-stopのNCループへ直列追加する。

パーツ選定:

| 項目 | 選定 | 備考 |
|---|---|---|
| メインコンタクタ | 密閉型DCコンタクタ(EVリレー)クラス。例: Hongfa HFE18Vシリーズ 100A、TE Kilovac EV200系 | 「24VDCを負荷電流で遮断できる」定格が必須条件。車載用12V系リレーはDC24V遮断定格が無いものが多く不可 |
| コンタクタコイル | 24Vコイル品。エコノマイザ(保持電流低減)内蔵型を優先 | 非内蔵ならコイル消費電力(数W)を5V/24V収支に入れる |
| E-stopスイッチ | 22mm ツイストリリース式・NC接点。例: IDEC XA/YWシリーズ、Omron A22E | NC接点をコイル電源ループに直列に入れる |
| コイルサージ対策 | フライバックダイオード(1N4007等)+ 必要ならTVS | 遮断応答を速くしたい場合はダイオード+ツェナー直列 |

電流の目安: C620は1台あたり連続20Aまで流せるが、本機の走行負荷での実測が先。初期は保守的に「メインヒューズ60A、コンタクタ100Aクラス」とし、実測後に見直す。

### 所有リレー KILIGEN E228 の扱い

所有品はKILIGEN `E228`、24V DC、100A表記の車載リレー。販売情報では100A表記に対して連続使用電流50〜60A、5時間連続作動後の停止を推奨している。また、メーカー正式データシート、25.2V DCにおける負荷遮断容量、誘導性/容量性負荷での遮断寿命を確認できない。

2026-07-26に、同一個体を前回ロボコン機体で約2000W（24V換算約83A）通電中にE-stop等で遮断できた実績と、24V/約75〜80mAのコイル仕様を確認した。この実績を正式なDC遮断定格の代替根拠として、`E228`を本機のメインコンタクタへ採用する。2026-08-06に、主回路をMOSFET式solid-state遮断器へ置換せず、この機械式コンタクタを継続する方針を再確認した。MOSFETはコンタクタコイル駆動、precharge、回生brake chopperに使用する。

ただし、メーカー正式データシートが無い残存riskは解消していない。今回の想定最大電流が実績値約83Aを明確に超えないこと、再利用前の主接点に摩耗・ピッティング・溶着兆候がないことを確認する。負荷試験で電流または温度に余裕がない場合は、24V DCでの負荷遮断定格がメーカー資料に明記された100A級DCコンタクタへ変更する。

## 表示灯

| 状態 | 表示 |
|---|---|
| 非常停止中 | 赤点灯 |
| エラー | 赤点滅 |
| 待機 / 未キャリブレーション | 黄点灯 |
| キャリブレーション中 | 黄点滅 |
| 動作可能 | 緑点灯 |
| 通信断 | 青点滅または赤黄交互 |

表示灯はGUIを見なくても安全状態が分かる位置に置く。

## 装飾・状態表示LED

非常停止表示とは別系統として、ミッション達成、通常状態、バッテリー残量などを示すテープLED/表示LEDを搭載可能にする。

- 安全状態を示す赤・黄・緑表示は、演出LEDが故障・消灯しても判別できる独立表示とする。
- LED系統は専用ヒューズ付き分岐とし、モータ電源ではなくE-stop後も生きる制御電源側から給電する。
- LED電圧、方式(単色/RGB/アドレサブル)、長さ、最大電流は未確定。決定後、既存5V/5A DC-DCへ収容可能か計算し、必要ならLED専用DC-DCを追加する。
- バッテリー残量表示は瞬時電圧だけでなく、Teensyが取得する電圧・電流と残量推定結果を使う。低電圧警告は演出より優先する。
- 24Vアナログ/RGBテープは中央基板上または外付けドライバ基板のMOSFETで駆動し、Teensy GPIOへ直接接続しない。
- 5VアドレサブルLEDを使う場合は3.3V→5Vレベル変換、電源入口のバルクコンデンサ、信号直列抵抗、電源注入位置を設計する。
