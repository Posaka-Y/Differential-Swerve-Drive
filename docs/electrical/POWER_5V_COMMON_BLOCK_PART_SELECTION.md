# 5V共通電源ブロック 部品選定

## 適用範囲

購入済み24V→5V/5A DC-DC以降の低電圧配電を対象とする。中央基板の5A主入力保護、24V一次側、Teensy枝、mini PC用12V系は負荷条件が異なるため、この選定をそのまま適用しない。

```text
中央基板: 5V/5A入力(XT30) -> 枝別PPTC -> 枝LED -> GH 2pin -> ハーネス
G474基板: GH 2pin -> LM66100 -> PWR_5V -> 5V負荷
                                              -> TLV1117LV33 -> 3V3
```

## 回路定数

### G474基板入力

- `SM02B-GHS-TB` pin 1=`PWR_5V_IN`、pin 2=`GND_CTRL`。
- `LM66100DCKR`: VINへ入力、VOUTを`PWR_5V`、`CE_N`はVOUTへ接続、STとNCは未接続。TIデータシート8.3節のRPP+RCB構成とし、逆極性保護に加えて出力側から入力側への逆流を遮断する。VIN側へ2.2uF以上を置く。
- LDO入力は100nF + 10uF、出力は100nF + 10uFのX7Rを初期値とする。各容量はDC bias後もデータシート最小値を下回らない品を選ぶ。
- `TLV1117LV33DCYR`のタブはVOUT。広い3.3V銅箔へ接続し、誤ってGNDヒートシンクへ接続しない。
- 5V負荷は`TCAN1051VDRQ1`、AMT22/AMT102等。3.3V負荷はSTM32G474、VIO、IMU等とする。

### 中央基板のG474枝

- 5Vバスから各ユニットx3とオドメトリ基板へ、`1206L050/15YR`を1個ずつ直列に入れる。
- PPTC後に緑LED + 1.5kΩを置く。LED電流はVf=2.0V時に約2.0mAで、ヒューズ前ではなく枝の保護後を表示する。
- 各枝にPPTC前5V、PPTC後5V、GNDのテストポイントを置く。
- Teensy、外部拡張、LEDテープの枝は0.5A品を自動流用しない。実測した定常電流、突入、最高周囲温度から個別選定する。

## 定格と熱

`TCAN1051V`はVCC=5V、VIO=3.3Vであり、以前の「CANトランシーバ2個を3.3V負荷に含む」計算は不採用とする。G474基板の3.3V実負荷を150～300mAと仮定すると、LDO損失は次の範囲になる。

| 3.3V電流 | LDO損失 `(5.0-3.3)×I` |
|---:|---:|
| 150mA | 0.255W |
| 200mA | 0.340W |
| 250mA | 0.425W |
| 300mA | 0.510W |

SOT-223の1A表記は熱的に1Aを常用できる意味ではない。VOUTタブ周囲の銅箔面積を確保し、実装基板で3.3V最大負荷時の温度を測る。300mAを恒常的に超える、または高温筐体で余裕がない場合は3.3Vスイッチング電源へ再選定する。

`1206L050/15YR`のIholdは周囲温度で低下する。データシート表では20℃=0.50A、40℃=0.42A、50℃=0.39A、60℃=0.35A、70℃=0.31A、85℃=0.25A。したがって0.5Aの精密遮断器とは扱わず、各G474枝の定常電流と起動電流を最高筐体温度で測って誤トリップしないことを確認する。

## 比較で不採用とした候補

| 候補 | 判断 |
|---|---|
| `MCP1826S-3302E/DB` | セラミック安定・SOT-223で成立するが、今回の調査ではTLV1117LVより少量価格と流通の利点が弱いため代替候補へ移す |
| `AMS1117-3.3` | メーカー違いの互換品が多く、出力コンデンサESR条件とdropoutが採用品より厳しいため新規採用しない |
| ショットキーダイオード逆接保護 | 単純だが電圧降下が常時発生し、5V末端電圧の余裕を減らす |
| ディスクリートPch MOSFET | 大電流化は容易だが、誤配線時の動作検証と部品点数が増える。G474枝はLM66100の1.5A範囲内 |
| `MF-MSMF050-2` | NRNDのため新規設計に使わない |
| 6V定格`1206L050YR` | 5Vバスでは動作範囲内だが、異常時余裕を取れる15V版を採用する |

## 配置・配線制約

1. GH入力直後にLM66100と入力コンデンサを置き、未保護5Vの基板内引回しを短くする。
2. LM66100のVIN/VOUT/GNDは面で接続し、細いネックやサーマルリリーフによる電圧降下を避ける。
3. LDOの入出力コンデンサは各ピンとGNDへ最短ループで置く。タブ側3.3V銅箔は放熱にも使う。
4. 中央基板のPPTCは各GH2コネクタの近くへ置き、枝間で保護後ネットを共通化しない。
5. 枝LEDはコネクタ横に並べ、シルクへ枝名を表示する。点灯は電圧存在表示であり、ノード正常動作表示ではない。
6. 5V/GNDの配線幅は枝の許容電流と銅厚からKiCad Calculatorで決め、コネクタ/PPTC/ビアを含む最細部を確認する。

## 実機確認

- 各G474基板の通常時、CAN高負荷時、センサー起動時の5V/3.3V電流。
- 40～60℃相当でPPTCが誤トリップしないこと。
- 5V極性反転時に基板側VOUTが立ち上がらず、正常極性へ戻して復帰すること。
- 別枝を短絡したとき、その枝だけが遮断され、Teensyと他ノードがリセットしないこと。
- 最大負荷でLDO、LM66100、PPTC、GH端子、ハーネスの温度と末端電圧。
