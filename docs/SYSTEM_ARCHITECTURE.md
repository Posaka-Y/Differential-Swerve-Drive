# システム全体構成

## 目的

差動ステアユニットを3基搭載した移動機構を構成する。

各ユニットは、2個のM3508と1個のAMT22を持つ自己完結型モジュールとして扱う。中央制御は各ユニットへ目標角と目標速度を送り、ユニット内でモーター協調制御とステア/速度ループを閉じる。

## 基本構成

```text
mini PC
  |-- GUI
  |-- ログ
  |-- キャリブレーション操作
  |
  | USB / UART / Ethernet
  v
中央制御基板 / Teensy
  |-- E-stop監視
  |-- 起動許可
  |-- CANバス管理
  |-- 各ユニットへ目標角・目標速を配信
  |
  | COMM_A / COMM_B / VIN_CONTROL / GND_CTRL
  v
差動ステアユニット x3
  |-- ユニット基板(STM32G474自作、開発検証はNUCLEO-G474RE)
  |-- C620 x2
  |-- M3508 x2
  |-- AMT22 x1
```

## 責務分担

| レイヤー | 担当 | 責務 |
|---|---|---|
| GUI | mini PC | 表示、設定、キャリブレーション操作、ログ |
| 中央制御 | Teensy | 安全判定、各ユニットへの指令、通信管理 |
| ユニット制御 | STM32G474自作基板 | AMT22読み取り、C620制御、ステア/速度ループ |
| 電力 | 中央分電盤 | 24V、12V、5Vの分配 |
| 安全 | E-stop回路 | C620主電源の物理遮断 |

## 制御方針

- 中央Teensyは各ユニットへ目標ステア角と目標駆動速度を送る。
- 各ユニットMCUはAMT22を直接読み、ステア角ループを閉じる。
- 各ユニットMCUはユニット内部CANでC620 x2へ指令を出し、差動ステアの2モーター協調を行う。
- 中央から見たユニットは、C620を直接操作する対象ではなく、ホイール回転数とステア角度で動くCANモジュールとして扱う。
- 中央-ユニット間通信は中央CAN(C620専用CANとは別バス)とする。G474REのFDCANを2系統使う。
- エンコーダ角を中央通信へ高周期で流さない。ユニット内で閉じる。
- 中央へ返すステータスは間引く。

## 電源方針

- 6S LiPo x2を電源源とする。
- C620 x6には6S相当の24V系をそのまま分配する。
- mini PCには24Vから12Vへ降圧して供給する。
- Teensy、センサ、各ユニット制御基板には24Vから5Vへ降圧して供給する。
- 各ユニット制御基板への基本ハーネスは `CAN_H / CAN_L / VIN_CONTROL / GND` の4線とする。
- C620用24V大電流ラインは制御4線とは別に太線で分配する。

## 安全方針

- 非常停止はソフト停止だけに依存しない。
- メインリレーまたはDCコンタクタでC620 x6への24V主電源を物理遮断する。
- 非常停止状態は表示灯で外部から確認できるようにする。
- mini PC GUIは起動要求を出すだけで、最終的なMotor Enable判定はTeensyが行う。
- mini PC通信断、CAN通信断、E-stop入力、未キャリブレーション時はMotor Enableを許可しない。

## 通信方針

ユニット外部接続は `VIN_CONTROL / GND_CTRL / COMM_A / COMM_B` の4線とする。

`COMM_A/B` は物理層を抽象化した名前で、実体は中央CANのCAN_H/CAN_Lとする(2026-07-02確定)。C620 CANはユニット内部専用とし、中央CANとは電気的に独立した別バスにする。
