5. AMT102-V入力 x3

各コネクタはSM04B-GHS-TB、pin 1=5V、2=GND、3=A、4=B。Z相は配線しない。

GH4 → ESDS452DBZR → 100Ω → SN74LVC2G17DBVR → STM32 Timer Encoder input

1 / TIM2 J501-3 → D501-1 → R511 → U501-1 → U501-6 → PA0 J501-4 → D501-2 → R512 → U501-3 → U501-4 → PA1
2 / TIM3 J502-3 → D502-1 → R513 → U502-1 → U502-6 → PA6 J502-4 → D502-2 → R514 → U502-3 → U502-4 → PA7
3 / TIM4 J503-3 → D503-1 → R515 → U503-1 → U503-6 → PB6 J503-4 → D503-2 → R516 → U503-3 → U503-4 → PB7

ESD保護

  • D501-D503: ESDS452DBZR
  • pin 1/2=A/B、pin 3=GND
  • 5.5V working、2ch双方向、SOT-23-3
  • コネクタ直近配置、GND帰路を短くする

Schmitt buffer

  • U501-U503: SN74LVC2G17DBVR
  • 3.3V給電、各100nF
  • pin 1=1A、2=GND、3=2A
  • pin 4=2Y、5=3V3、6=1Y
R511-R516は100Ω初期値。C511-C516は入力からGNDへのRC調整用0603で初期DNP。 容量は最大入力周波数と実波形を確認してから決める。

9. 初回ERC前チェック

  1. F405の全VDD/VSS、VDDA/VSSA、VBAT、VCAP_1/2が接続されている。
  2. VCAPは各2.2uF以外へ接続されていない。
  3. CANはPA12 → TXD、RXD → PA11であり逆でない。
  4. TCANのVCC=5V、VIO=3.3V、S=GND。
  5. TLV1117のtab/pin 2が3V3であり、GNDでない。
  6. AMT102コネクタは1=5V、2=GND、3=A、4=B。
  7. ESDS452はpin 1/2=A/B、pin 3=GND。TVSが100Ω抵抗よりコネクタ側にある。
  8. SN74LVC2G17のVCC=3.3V、各ICへ100nF。
  9. IMUは3.3V給電で、CSのLow activeとINT方向を注記している。
  10. UNIT_IDはPC6/7/8で、unitId=4設定がシルクで読める。
  11. 未使用MCU pinにNo Connectを明示している。
  12. ERC後にPDFを出し、本書の接続表と1:1照合する。
